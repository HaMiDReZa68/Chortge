# حسابداری پیامک

اپ اندروید (Kotlin + Jetpack Compose) که پیامک‌های بانکی را می‌خواند، هر تراکنش را دسته‌بندی می‌کند و گزارش ماهانهٔ شمسی می‌دهد.

## گرفتن APK بدون Android Studio
1. یک ریپوی جدید در GitHub بساز و کل این پوشه را در آن آپلود کن (شاخهٔ `main`).
2. به تب **Actions** برو؛ بعد از چند دقیقه بیلد تمام می‌شود.
3. روی آخرین اجرا کلیک کن و فایل `SmsAccounting-apk` را از بخش Artifacts دانلود کن؛ داخلش `app-debug.apk` است.

## گرفتن APK با Android Studio
پوشه را باز کن و از منوی Build گزینهٔ Build APK(s) را بزن.
فایل در `app/build/outputs/apk/debug/` ساخته می‌شود.

## نکته‌های نصب
- در اندروید ۱۳ به بالا، برای اپ‌های نصب‌شده از بیرون فروشگاه، اگر اجازهٔ پیامک خاکستری بود:
  تنظیمات ← برنامه‌ها ← حسابداری پیامک ← منوی سه‌نقطه ← Allow restricted settings، بعد دوباره اجازه را بده.
- اپ هیچ دسترسی به اینترنت ندارد؛ همهٔ داده‌ها فقط روی گوشی می‌ماند.
